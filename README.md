# 한국인을 위한 해외생활 가이드

**미국·호주·일본｜정착·유학과 취업·여행과 가족 방문**

[읽기·검색](https://gerrygao1995-coder.github.io/korean-overseas-life-guide/) · [대상과 이용 안내](EDITION.md) · [함께 고치기](CONTRIBUTING.md)

미국·호주·일본의 생활 정보를 해외에 정착하고, 공부하고, 일하고, 여행하는 한국인을 위해 정리했습니다. 이 판에는 미국·호주·일본을 수록하며 한국 국내편은 제외합니다.

128개 장, 원자료 1688개 항목을 담았습니다. 현지 시민권을 취득한 한국 출신 주민, 한국 국적 영주권자, 비자 체류자, 단기 방문자의 조건을 구분합니다. 국적만으로 의료·급여·취업 자격을 판단하지 말고 각 항목의 이용 경로부터 확인하세요.

## 읽는 방법

국가별 첫 안내에서 체류자격과 보험을 확인한 뒤 필요한 장을 검색해 펼칩니다. 저장 목록은 본인의 브라우저에만 남습니다. 내려받은 `index.html`을 열면 본문 전체를 오프라인에서 읽을 수 있습니다. 출처 사이트는 인터넷 연결이 필요합니다. GitHub에서 긴 본문을 생략하면 읽기 페이지나 다운로드를 이용하세요.

## 출처·번역·공동 편집

원언어에서 기계 번역한 초안을 바탕으로 국적·체류자격에 따른 이용 경로와 주요 표현을 모델이 교정했습니다. 전문 번역가의 전 문장 대조 검토, 모든 제도의 개인별 자격 심사, 모든 출처의 동일 날짜 재검증을 완료한 것은 아닙니다. [TRANSLATION.md](TRANSLATION.md)에 검토 범위, [ATTRIBUTION.md](ATTRIBUTION.md)에 원저작물과 변경 내용을 명시했습니다.

본문은 CC BY 4.0, 읽기 코드는 MIT입니다. 출처·저자·수정 내역을 유지하며 공유하고 고칠 수 있습니다. 제삼자의 링크 자료에는 각자의 권리가 적용됩니다. Issue와 Pull Request로 국가·항목ID·대상 체류자격·공식 근거·확인 날짜를 제시하여 수정에 참여할 수 있습니다.

이 자료는 일반적인 참고 안내입니다. 의료·법률·세무·체류자격의 중요한 판단은 최신 공식 정보와 개인 조건을 확인하세요.
